🚀 GitHub 部署指南

6 步完成 · 全自动每日更新 · iPhone 可加主屏幕
1
注册/登录 GitHub 账号
你已经有 GitHub 账号了，这步直接 ✅
2
创建 GitHub 仓库

访问 github.com/new，按下面填写：

⚫ ⚫ ⚫ Create a new repository
Repository name *
easylumi-workbench
Description (optional)
Easylumi 工作台
● Public ○ Private
☑ Add a README file
Create repository →
⚠️ 重要：必须选 Public（公开），否则 GitHub Pages 用不了。
3
上传所有文件到仓库

在仓库主页，点 「Add file」→「Upload files」

⚫ ⚫ ⚫ zhao-yixi-easylumi / easylumi-workbench
+ Add file ▼ Code ▼

打开你电脑文件夹 E:\workboddy\2026-08-01-10-59-13，把下面这些文件和文件夹全部拖进上传框：

📂 需要上传的：
  • index.html — 主页面
  • manifest.json — PWA 配置
  • sw.js — 离线缓存
  • icons/ 文件夹（含3张图标）
  • backend/ 文件夹（含 fetch_hot.py + requirements.txt）
  • .github/ 文件夹（含 workflows/daily-hot.yml）
  • data/ 文件夹（含 hot_data.json）

上传后，提交信息填 "初始上传 Easylumi 工作台"，点绿色 「Commit changes」

4
配置 DeepSeek API Key（密钥）

在仓库页面，点顶部 「Settings」 → 左侧 「Secrets and variables」→「Actions」

如果左侧菜单不显示，试试直接访问：
https://github.com/你的用户名/easylumi-workbench/settings/secrets/actions

点 「New repository secret」，添加：

Name Secret（填什么）
DEEPSEEK_API_KEY 你的 DeepSeek API Key（sk- 开头那串）
💡 只需要配这 1 个密钥。不需要 Token，不需要 Gist。
5
开启 GitHub Pages + 手动跑一次 Actions

① 开启 GitHub Pages：

仓库 → Settings → 左侧 「Pages」

  • Source：选 「Deploy from a branch」
  • Branch：选 「main」，文件夹选 「/(root)」
  • 点 「Save」
  • 等 1-2 分钟，页面顶部会出现网址：
    https://用户名.github.io/easylumi-workbench/

② 手动跑一次 Actions（测试）：

仓库 → 顶部 「Actions」 → 左侧点 「Easylumi 每日热榜更新」 → 右侧点 「Run workflow」→ 绿色「Run workflow」

⚫ ⚫ ⚫ Actions · Easylumi 每日热榜更新
This workflow has a workflow_dispatch event trigger. Run workflow ▼

等 2-3 分钟跑完后，回到仓库主页，确认 data/hot_data.json 已更新。

6
iPhone 添加到主屏幕

1. iPhone 用 Safari 打开你的 GitHub Pages 网址：

https://你的用户名.github.io/easylumi-workbench/

2. 点 Safari 底部中间的 分享按钮（方框带箭头 ↑）

3. 往下滑，点 「添加到主屏幕」

4. 点右上角 「添加」

🎉 完成！以后从 iPhone 桌面直接打开，就是独立 App 体验。
GitHub Actions 每天自动 8:00 + 20:00 更新热榜数据。
